# Sales Performance Analysis using Python, SQL & Matplotlib

## Project Overview

This project analyzes retail sales data using Python, Pandas, SQL, and Matplotlib. The goal is to identify sales trends, analyze product performance, and generate business insights through data analysis and visualization.

## Tools Used

- Python
- Pandas
- NumPy
- SQLite
- Matplotlib
- Google Colab
- Google Looker Studio

## Dataset

Sample Superstore Dataset

## Project Workflow

1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. SQL Analysis
5. Data Visualization
6. Interactive Dashboard Creation
7. Business Insights

## SQL Concepts Used

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- LIMIT
- COUNT()
- SUM()
- AVG()

## Visualizations

- Category-wise Sales
- Monthly Sales Trend
- Region-wise Sales Distribution
- Sub-Category Sales Analysis

## Interactive Dashboard

Created an interactive sales performance dashboard using Google Looker Studio.

### Dashboard Features

- Total Sales KPI
- Total Profit KPI
- Total Orders KPI
- Category filter
- Date range filter
- Sales by Category
- Sales by Region
- Monthly Sales Trend
- Sales by Sub-Category
- Interactive chart filtering


## Live Dashboard

[View Sales Performance Dashboard](https://datastudio.google.com/reporting/07016e1f-b530-4f57-be14-ca9f4d80a6c8)

## Key Business Insights

- Technology generated the highest sales and profit.
- West region recorded the highest sales.
- November had the highest monthly sales.
- Canon imageCLASS 2200 Advanced Copier was the top-selling product.
